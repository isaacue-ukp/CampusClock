# CampusClock · 课表与作业

## Owner's words

An AI-assisted software application for managing campus class schedules.

The major feature is a floating ball on the desktop, which displays the schedule when the mouse hovers over it, without opening the app's main window.

Another feature is that users can add and edit homework directly through the floating ball. To be honest, that's what drove me to create this program.

Schedules in `.ics` format are supported.

## 简介
一个完全本地运行的 Windows 桌面小工具：读取 `.ics` 课表、显示本周课程、记录每门课的作业，并在桌面提供一个会自动展开的悬浮球。

- 不需要登录、不联网、不写注册表，所有数据都在本文件夹的 `data\` 里
- 单文件程序 `CampusClock.exe`，依赖 Windows 自带的 .NET Framework 4.8（Win10/11 默认已有）

## 快速开始

1. 双击桌面上的 **CampusClock** 快捷方式（或直接运行 `CampusClock.exe`）。
2. 窗口打开后会显示课表；没有课表时点右上角「导入课表」选择 `.ics` 文件。
3. 桌面右侧会出现悬浮球：**鼠标移到左半边展开课表，移到右半边展开作业**，鼠标移开自动收回。

## 三个模块

| 模块 | 用途 |
| --- | --- |
| 课表 | 一周课程表格。**纵轴是按真实时间等比的**（见下节），显示课程名、时间、地点；当天列和「现在」的位置会高亮。上方可切换上一周 / 下一周 / 回到本周 |
| 作业记录 | 先在上方点选「有作业的课程」，下方就会列出这些课程；点左侧圆圈打勾表示完成，完成的整行文字会变灰并加删除线 |
| 显示设置 | 字号、单元格宽高、卡片浓度、强调色、周末显示、悬浮球参数、作业清空规则、数据目录 |

## 课表的纵轴：按真实时间排列

- 纵轴是一条连续的时间轴，**每小时一条淡淡的虚线**，标注 `08:00`、`09:00`…
- 课程是一个圆角矩形，**上边缘 = 上课时间，下边缘 = 下课时间**，高度和真实时长成正比：一节 1 小时的课就占 1 小时的高度，1 小时 50 分的课就占 1 小时 50 分。
- 因此上午、下午、晚上之间若没有课，就会自然留出空白，一眼能看出哪段时间是空的。
- 12:00 与 18:00 有稍明显的分界线，背景还带极淡的「上午 / 下午 / 晚上」分段底色与标注。
- 完全不受「第几节」限制：例如 15:10–18:00 这种跨三节的课，或者 07:30、22:40 这种非标准时间，都能正常显示。
- 如果同一天有两门时间重叠的课，会自动**左右分列**并排显示。
- 纵轴缩放由「显示设置 → 时间轴缩放」控制（每小时多少像素，28 ~ 200），调大更宽松、调小更紧凑；调大后可以上下滚动，日期标题会固定在顶部。

## 悬浮球

- 收起的形态是**横向圆角矩形**（宽 ≈ 1.6 × 高，高度就是「悬浮球尺寸」的设置值），左半边「课表」、右半边「作业」，两块各自的图标与文字都在自己的半边内居中，鼠标悬停那一半就展开对应内容。
- **左半边**悬停 → 展开课表；**右半边**悬停 → 展开作业。展开后右上角有「课表 / 作业」切换按钮。
- 展开尺寸默认占桌面面积约 20%（接近 1/4 ~ 1/5 桌面），长宽比 1:1，可在「显示设置 → 桌面悬浮球 → 展开尺寸」里调整（8% ~ 45%）。
- 拖动悬浮球可移动位置；展开状态下拖动顶部标题栏可移动面板。
- 面板右上角三个按钮：📌 固定展开（不自动收起）、⧉ 打开主窗口、✕ 收起。
- 在悬浮球上点右键：打开主窗口 / 固定展开 / 始终置顶 / 隐藏悬浮球 / 退出。
- 想彻底关掉悬浮球：主窗口右上角「悬浮球：开/关」按钮，或「显示设置」里的开关。

## 作业自动清空规则

在「显示设置 → 作业记录 → 清空时机」里选择：

| 模式 | 行为 |
| --- | --- |
| 每次课后（默认） | 该课程任意一节课上完（按课表结束时间）就清空这门课的作业内容并取消打勾，等你重新填写 |
| 每天首次课后 | 同一天只清空一次，之后当天再上这门课不会重复清空 |
| 手动 | 完全不清空，只保留你手动填写与打勾的内容 |

说明：

- **第一次**启用某个课程时会以「当前最近一次已上完的课」作为基准，**不会**立刻清空你已经写好的内容；从下一节课开始生效。
- 清空只影响作业文本和打勾状态，不影响课表。
- 清空发生时窗口右下角会弹出提示，日志写在 `data\app.log`。

## 数据与备份

所有数据都在程序目录的 `data\` 文件夹：

| 文件 | 内容 |
| --- | --- |
| `timetable.ics` | 当前课表（导入时会复制一份到这里，桌面原文件可以随便移动或删除） |
| `config.json` | 显示设置、悬浮球位置和状态、作业清空规则、参与跟踪的课程 |
| `homework.json` | 每门课的作业内容、是否完成、上次清空时间 |
| `app.log` | 运行日志（排查问题时看这个） |

备份或换机时，把整个 `CampusClock` 文件夹复制过去即可。

## 常见问题

**点关闭按钮后程序不见了？**
默认最小化到托盘（右下角时钟旁的小图标）。双击托盘图标可重新打开窗口；右键托盘图标 → 退出 CampusClock 才是真正退出。

**悬浮球找不到了？**
在「显示设置 → 桌面悬浮球 → 悬浮球位置」点「复位到右下角」，或确认「启用悬浮球」是打开的。

**课表太挤 / 字太小？**
「显示设置」里调「字体大小」「单元格宽度」「时间轴缩放」，下方有实时预览。调大之后课表可以上下、左右滚动，日期标题栏和时间刻度会固定在边缘。

**作业内容被清空了，能撤回吗？**
不能自动撤回。如果希望永远不自动清空，把「清空时机」改成「手动」。

**换了新学期的课表怎么办？**
点「导入课表」选新的 `.ics` 即可，旧文件会被覆盖；已选课程若不在新课表里会自动从跟踪列表移除。

**支持什么格式的课表？**
标准 iCalendar（`.ics`）。逐周重复（`RRULE:FREQ=WEEKLY`）、`UNTIL`、`INTERVAL`、`BYDAY`、`EXDATE`、时区（`TZID`，含 UTC）都支持；`第X-Y节` 的节次信息会从 `DESCRIPTION` 里读取，读不到时用时间显示。

## 源码与重新编译

源码在 `src\*.cs`（C# 5 / WPF，无第三方依赖）。修改后在本文件夹运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

会重新生成 `CampusClock.exe`（自动带上图标）。另有一个无界面自检模式，用于验证解析与界面构建：

```powershell
.\CampusClock.exe --selftest --ics .\data\timetable.ics
```

结果会打印出来并写入 `data\selftest.log`。

## 系统要求

- Windows 10 / 11（x64 或 ARM64 均可，程序为 AnyCPU）
- .NET Framework 4.8（Windows 10 1903 之后、Windows 11 默认自带）
- 不需要网络、不需要管理员权限、不需要登录
