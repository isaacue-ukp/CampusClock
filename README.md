# CampusClock
An AI-assisted application concerning class schedule in campus. Developed by Codex, with Deepseek v4flash in. It costs me ￥1.3.

The major feature is a floating ball on the desktop, whose function is to display the schedule without opening the app's window when the mouth hovers over it.

Another feature is that the user can add and edit homework in the app. Display of homework is also included in the floating ball. To be honest, that's what drove me to develop the program.

Schedules in .ics format are supported.
